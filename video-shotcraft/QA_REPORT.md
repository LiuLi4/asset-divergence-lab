## 逐镜头自检

- R1 ✓ 收尾品牌卡从第 1128 帧前后进入，GitHub 地址稳定停留超过 3 秒。
- R2 ✓ 候选 A/B/C 以 10 帧错峰依次从正面翻到结论面，末尾保留超过 0.5 秒静止。
- R3 ✓ 点击、模式切换和小区下钻均按真人可跟随速度执行；每个功能镜头 5–5.5 秒。
- Q1 ✓ 所有产品页面与既有 UI 均来自本地真实项目截图；只额外制作字幕、光标、定位点和品牌舞台。
- Q2 ✓ 页面截图使用 2× device scale factor 采集；地图原图为 3840 × 2160。
- Q3 ✓ 全片没有随机抖动或手持噪声。
- Q4 ✓ 没有群发扫光；聚光仅用于小区价值详情主角。
- Q5 ✓ 开场只有一个主动作：北京全图俯冲西城区。
- Q6 ✓ 信息密集的现金流、矩阵和候选评分均保持正视。
- Q8 ✓ 收尾召回地图、小区详情、周边、模式切换、曲线、压力矩阵、候选评分等 8 类素材，以四向错峰飞入、舞台光和确定性粒子围拢品牌卡。
- Q11 ✓ 叙事字幕 64px；辅助文字、功能胶囊、OSM 署名与 URL 均不低于 32px。
- S1 ✓ 使用可追溯的 House BGM 和电影系 whoosh / impact / transition / sparkle；未使用合成游戏提示音。
- S2 ✓ SFX 以镜头起点加相对偏移集中声明，候选卡使用双样本、10 帧错峰和递减音量。
- S3 ✓ 最终字号与授权素材替换后已重新渲染并重新核对音频峰值。
- S4 ✓ 点击使用真实快门声，自住/出租切换使用真实机械开关声；长音效均显式截断。
- C1 ✓ 8 个镜头均有与当前页面状态一致的结论字幕，品牌收尾保持干净。
- C2 ✓ 文案直接使用地图证据、现金流、压力测试、候选评分等产品功能名。
- P1 ✓ 从最终 MP4 抽取 16 个验收帧，覆盖每镜头动作中段与落定状态；最终 contact sheet 为 `out/qa/final-contact-sheet.png`。
- P4 ✓ 地图、小区、周边、买租、曲线、压力矩阵、候选评分、开源地址均有独立镜头，没有重复功能镜头。
- 独立终检 ✓ S2 小区点选与 S3 详情卡立体动效的返工项通过；版本哈希、16 张有序验收帧与八镜头覆盖全部通过，无必须修复项。
