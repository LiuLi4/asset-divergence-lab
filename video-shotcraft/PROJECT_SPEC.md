# 北京买房决策工具 · 抖音竖屏宣传片制作规范

## 创作模式与硬约束

- 模式：video-shotcraft 自主自由创作
- 发布场景：抖音信息流
- 画幅：1080 × 1920，30fps，H.264 MP4
- 时长：42 秒（1260 帧）
- 语言：简体中文
- 交付：带 BGM 版、无 BGM 但保留 SFX 版
- 已锁定主镜头：`space-camera-moves · drone-dive-landing`
- 页面呈现：只使用项目真实页面截图，不重绘产品 UI
- 数据：仅展示仓库已公开的派生小区评分和演示输入；不展示个人、客户、内部或实时敏感数据
- 地图：OpenStreetMap 画面必须保留署名

## 产品简报

这是一个面向北京购房者的开源决策工具。它不预测房价，而是把“要不要买、买哪套”拆成可核验的地图证据、逐月现金流、压力测试和候选房源评分。

核心受众是 24–40 岁、正在北京看房、愿意用数据辅助判断的用户。宣传片的第一任务不是解释公式，而是让观众在前三秒明白：这里能从北京全图一直看到具体小区，并继续验证买房决策。

## 需求到执行决策

| 需求 | 执行决定 | 影响 |
|---|---|---|
| 抖音竖屏 | 中央轴构图，标题和关键数字进入上下安全区 | 不直接把横屏录屏缩小塞进手机画面 |
| 前三秒留人 | 北京全图直接俯冲西城区 | 不使用慢速品牌字标开场 |
| 真实可信 | 使用本地项目真实截图和公开派生数据 | 不使用虚构楼盘 UI |

| 可静音观看 | 每个镜头都有一句结论字幕 | 无旁白也能看懂 |
| 音频可复用 | BGM 与 SFX 解耦 | 同时间线输出两版 |

## 视觉方向

### 候选方向

1. 城市证据航拍：以 3D 北京地图为视觉原点，镜头像勘察机一样逐层下钻。
2. 数据实验室：强调表格、曲线和参数变化，专业但地图辨识度不足。
3. 房产编辑部：纸张、批注和大字报更有人味，但会削弱真实工具感。

### 定案：城市证据航拍

取舍：用项目自己的地图和淡紫纸感建立辨识度；只在开场和收尾使用大动作，中段以清晰阅读为主。整片三个动效关键词：**精准、下钻、克制**。

### 视觉 tokens

- 背景：`#f1eefb`、`#f5edf8`
- 主要文字：`#251044`
- 次要文字：`#756987`
- 紫色强调：`#7760b3`
- 高价值：`#147a5d`
- 谨慎观察：`#a66b16`
- 风险：`#b44b59`
- 表面：`rgba(255,255,255,.92)`
- 圆角：主画面 42px；信息胶囊 999px；详情卡 24px
- 阴影：`0 30px 90px rgba(50,26,83,.18)`
- 字体：系统中文无衬线，数字使用等宽数字
- 标题：72–92px / 1.06 / 700
- 字幕：60–66px / 1.25 / 650
- 辅助标签：24–28px / 1.4 / 600

### 动效 tokens

- 品类：专业信赖，能量轴中高，调性轴严肃偏亲和
- 常规入场：21–27f，`cubic-bezier(0,0,0.2,1)`
- 常规过冲：无；只有真实落地隐喻允许 ≤1.04
- 开场俯冲：25f 吃 82% 行程，20f 气垫减速完成剩余 18%
- 信息落定：至少 30f 静止
- 批量动作收尾：至少 15f 静止
- 不使用手持抖动、群发泛光或游戏式提示音

### 音频方向与授权

- BGM：Lily J《House Vibez》，从原始约 123 BPM 等比例放慢到 120 BPM，Mixkit Stock Music Free License
- 选曲理由：鼓点稳定、节奏明确，能托住地图俯冲和发布会式收尾；曲名、作者和原始下载地址可复核
- SFX：只使用有逐文件 Mixkit 原始地址的素材；开场俯冲、真实点击、地图推进、模式切换和收尾三拍均按镜头相对帧号钉帧
- 成片音频峰值必须低于 0dB，并交付无 BGM、保留 SFX 的同时间线版本

## 制作放行记录

- 产品简报覆盖地图与决策工具，没有把产品缩窄成单一资产分化计算器。
- 所有页面状态均可从公开本地演示数据生成。
- 每镜只承担一个主要动作，字幕不重复 tagline。
- 开场、批量动作和收尾均预留阅读 hold。
- 竖屏、安全区、双音频版本和 OpenStreetMap 署名已进入硬约束。

结论：阶段 0–3 一致，放行进入最终素材采集。
