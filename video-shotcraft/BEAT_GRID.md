# BGM 节拍网格

成片为 30fps。BGM 使用 Lily J《House Vibez》，将原始约 123 BPM 以 `atempo=120/123` 等比例放慢到 120 BPM。

- 120 BPM = 每拍 0.5 秒 = 每拍 15 帧
- 节拍相位：第 0 帧
- 镜头切点：0 / 150 / 300 / 450 / 600 / 765 / 930 / 1080 帧
- 对应拍号：0 / 10 / 20 / 30 / 40 / 51 / 62 / 72
- 所有主镜头切点均落在节拍网格，理论误差 0 帧

时间线如果修改镜头长度，必须重新检查上述拍号并同步重钉 SFX 相对偏移。
