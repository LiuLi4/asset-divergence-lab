# 北京房产价值评估 · 在线体验

[立即体验](https://liuli4.github.io/asset-divergence-lab/)

这是“北京房产价值评估”的公开部署仓库，只保存网站运行所需的编译产物、许可声明和 GitHub Pages 工作流。

完整源码、测试、数据处理脚本和 Git 历史保存在私有核心仓库中，不在此仓库公开。浏览器可以下载网站运行所必需的 JavaScript、CSS、图片和公开数据。

## 能做什么

- 浏览北京房屋交易价值地图和小区价值点位
- 从北京全图下钻到区县、小区及周边街区
- 查看小区证据、价值评分与买房方案
- 根据最新官方政策基准测算公积金和商业贷款
- 比较买房、租房与不同房价情景下的长期现金流
