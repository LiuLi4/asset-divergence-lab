# 资产分化实验室

一个面向北京购房者的开源决策实验工具。它不预测房价，而是把“要不要买、买哪套”拆成两套透明工具：逐月现金流模型与房源证据评分卡。

在线体验：<https://liuli4.github.io/asset-divergence-lab/>

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址。提交前可运行完整校验：

```bash
npm run check
```

## 当前功能

- 自住「买房 vs 租住 + 理财」与出租投资两种比较口径
- 组合贷款、等额本息、剩余本金和累计利息的逐月计算
- 买入、卖出、装修、持有成本和租金增长假设
- 房价涨幅 × 理财收益双变量压力测试
- 用二分法求解买房与替代投资终值相等的临界涨幅
- 收入下降后的月供压力测试
- 三个候选房源的独立命名、六维加权评分和并排比较
- 浏览器本地自动保存，支持下载包含输入、结果和房源评分的 JSON 报告
- CSS 3D 资产地形、鼠标视差与滚动出现动效
- Three.js 北京行政区 3D 地图、环路、中央轴线与资产节点
- 北京地图区县下钻与小区购买价值图层：7,972 个授权小区点位、三档分数颜色、数据不足状态、同质折价和成交样本详情
- 默认加载获授权的生产数据；仍可在浏览器本地导入最多 50,000 个小区的 JSON 数据覆盖默认数据，文件不会上传
- 内置可复现的北京七区 OSM 坐标底表构建流程；当前快照含 4,590 个住宅要素并保留 ODbL 署名
- GSAP ScrollTrigger 驱动首屏推进、章节揭示和结果动效
- 支持 `prefers-reduced-motion` 动效降级
- 响应式布局，适配移动端

## 公式说明

```text
房产终值 = 房屋总价 × (1 + 房价年涨幅) ^ 持有年限
期末净卖房权益 = 房产终值 × (1 − 卖出成本率) − 剩余贷款
租住理财终值 = (首付 + 买入成本 + 装修)终值 + 每月(持有支出 − 租金)终值
买房优势差额 = 买房路径终值 − 替代投资路径终值
临界涨幅 = 使买房优势差额等于 0 的房价年涨幅数值解
```

计算内核位于 `src/finance.ts`，回归测试位于 `src/finance.test.ts`。页面提供北京公积金、房地产数据与购房资格官方入口，所有默认值均可编辑。

小区数据 JSON 格式、评分口径、覆盖率和授权边界见 [`docs/community-data.md`](docs/community-data.md)。仓库只发布派生后的地图评分文件，不再分发原始成交明细；无近 180 天成交或少于 3 个同质可比样本的小区明确标为“数据不足”，不会生成伪精确分数。

> 这是教育型决策工具，不构成投资、贷款、税务、法律或购房建议。真实决策仍需复核资格、利率、税费、产权、空置、维修、迁徙和流动性折价等个体因素。
